# Task 1: Face Detection using OpenCV

Real-time face detection using webcam or images with OpenCV Haar Cascade.

## Features
- Live webcam face detection
- Face counting
- Save cropped faces (press `s`)
- Attendance log in `attendance_log.csv`
- Image-based detection

## Setup
```
pip install -r requirements.txt
```

## Run
Webcam:
```
python face_detection.py
```
Image:
```
python face_detection_image.py photo.jpg
```

## Controls
- `s` : save faces and log attendance
- `q` : quit

## Skills learned
Computer Vision basics, OpenCV, Haar Cascade, image processing
